# world paketi — ajan talimatı

Sen **yalnızca `src/world/`** altına yazarsın. Kök `AGENTS.md` tüm kuralları içerir;
`spec.md` bu paketin sözleşmesidir. Başka pakete dokunma, `index.html`'i elle düzenleme,
build ve testleri çalıştırma — orkestratör yapar.

Başka pakette değişiklik gerekiyorsa `reports/requests/world.md` dosyasına tek satır not bırak.
